Система бронювання та купівлі залізничних квитків.

- `Лабораторна_№1` — UML діаграми (PlantUML-джерела та PNG) і звіт
- `Лабораторна_№2` — клієнтська частина (GUI) і звіт
- `Лабораторна_№3` — серверна частина (TCP + SQLite) і звіт
- `Лабораторна_№4` — повна система, тести і звіт
